# My Website

## 프로젝트 구조

```
📁 프로젝트 폴더
├── index.html       ← 메인 HTML 파일
├── css/
│   └── style.css    ← 스타일시트
├── js/
│   └── main.js      ← JavaScript 파일
└── README.md        ← 프로젝트 설명
```

## 시작하기

1. `index.html` 파일을 브라우저에서 열기
2. 또는 Live Server 확장을 사용하여 실행

## 기술 스택

- HTML5
- CSS3
- JavaScript (ES6+)

## 페이지 구성

- **헤더**: 사이트 제목 및 네비게이션
- **메인**: 콘텐츠 영역
- **푸터**: 저작권 정보
