# 픽셀아트 시네마틱 「飛翔」 — 빌드 스펙

> 이 문서는 키로(Kiro)가 스토리보드를 이해하고 픽셀아트 시네마틱을 구현하기 위한 기준 문서입니다.
> **업로드된 스토리보드 이미지는 전부 참고용 원화입니다.** 실제 에셋으로 그대로 쓰지 않으며, 구도·색상(팔레트)만 참고해 픽셀아트로 새로 제작합니다.
> 또한 버튼·자막·전환 등 UI 레이어는 이미지가 아니라 코드로 렌더링합니다.

---

## 1. 프로젝트 개요

- **형태**: 클릭(탭)으로 진행되는 선형 픽셀아트 시네마틱. 완전한 인터랙티브 무비는 아님.
- **진행 방식**: 컷 안의 나레이션/액션이 **한 비트씩** 노출되고, 클릭할 때마다 다음 비트 → 다음 컷으로 넘어감(원안의 `(다음)`에 해당). 자동 재생 아님.
- **분기**: 엔딩에서만 발생. `다시보기` / `나가기` 버튼.
- **렌더링**: HTML `<canvas>` 기반. 프레임 이미지를 캔버스에 올리고, 나레이션/자막/전환 이펙트를 코드로 오버레이.
- **비주얼 톤**: 픽셀아트, 실루엣 중심, 화면비 전환으로 심리 상태 변화 표현.

## 2. 화면비 (결정 필요)

원안 텍스트와 스토리보드가 다릅니다. 구현 전 확정이 필요합니다.

| 구분 | 원안 의도 | 스토리보드 실제 |
|---|---|---|
| 일상 파트 | 16:4 (레터박스, 답답함) | 16:9 |
| 비상 파트 | 3:4 (세로, 낙하 방향성) | 16:9 |
| 착지 파트 | 1:1 (사방의 시선) | 16:9 |

**권장**: 화면비 변화 자체가 서사 장치이므로, 캔버스 표시 영역(viewport mask)을 컷별 `ratio` 값으로 제어하고 나머지는 레터박스 처리. 스토리보드가 16:9로 그려졌더라도 표시 마스크만 바꾸면 됨.

## 5. 씬 데이터 스키마

각 컷을 아래 구조의 배열로 정의합니다. 키로는 이 스키마 기준으로 `scenes.json`을 생성/렌더링합니다.

```json
{
  "id": "s01_room_wake",
  "image": "assets/s01_room_wake",
  "ratio": "16:9",
  "bgm": { "track": "calm_ambient", "action": "start" },
  "sfx": [],
  "transitionIn": "cut",
  "beats": [
    { "type": "action",    "text": "남자 일어나서 핸드폰을 확인한다" },
    { "type": "narration", "text": "인생은 삶의 반복이다." },
    { "type": "narration", "text": "아침은 지겨울 정도로 허기지고" }
  ],
  "advance": "click"
}
```

- `type`: `action`(연출 지시, 자막 미노출 가능) / `narration`(자막 노출)
- `transitionIn`: `cut`(효과 없음) / `glitch_rgb` / `iris_out` / `fade` / `slide_down` / `natural`
- `bgm.action`: `start` / `keep` / `fadeout` / `loop`
- `sfx`: 해당 컷 진입 또는 특정 비트에서 재생할 원샷 효과음 배열

## 7. 인터랙션 스펙 (엔딩 전용)

`s22`에서 박수/쇼 종료음이 무한 반복되는 상태로 버튼 대기.

- **다시보기 클릭** → 상태 리셋 후 `s01_room_wake`로 이동 (전체 루프)
- **나가기 클릭** → 화면을 벗어날 수 없다는 연출. `다시보기` 버튼이 **무작위 위치로 80개** 생성되어 화면을 가득 채움. (나가는 선택지가 없다는 아이러니)
  - 80개 버튼 각각도 클릭 시 `s01`로 이동하게 처리 권장.

```
[s22 박수 무한반복]
   ├─ 다시보기  → reset() → goto s01
   └─ 나가기    → spawnRematchButtons(count = 80, position = random)
```

## 10. 결정/확인 필요 항목

1. **화면비**: 16:9 통일 vs 원안(16:4 → 3:4 → 1:1) 전환 연출. (2번 참고)
2. **꽃 성장 애니메이션(`s16~s19`)**: 프레임 4장 크로스페이드로 갈지, 실제 성장 애니메이션으로 갈지. 원본에도 "가능한가" 메모 있음.
3. **P9 컷 순서**: 극장(s20) → 아이리스(s21) → 버튼(s22) 순서 확정 여부.
4. **혈흔/주황머리 색**: 원본 추출값이 약함. 권장값(`#B0342A`, `#EC5A2E`) 사용 여부.
5. **진행 방식**: 전 구간 클릭 진행 vs 일부 자동 재생 혼용 여부.
6. **자막 언어**: `さよなら` 등 원문 유지 여부.

## 11. 사운드 파일 규칙

음악/효과음 파일을 `assets/audio/` 폴더에 아래 네이밍으로 넣으면 자동 적용됩니다.
파일이 없으면 Web Audio 합성음으로 fallback됩니다.

### BGM (배경음악) — `assets/audio/bgm_{name}.mp3`

| 파일명 | 사용 씬 | 분위기 |
|---|---|---|
| `bgm_calm.mp3` | s01~s03 | 조용하고 선선한 앰비언트 |
| `bgm_footsteps.mp3` | s04~s05 | 뚜벅뚜벅 발소리 |
| `bgm_fresh.mp3` | s06~s07 | 파도소리 같은 신선한 사운드 |
| `bgm_classic.mp3` | s09~s11 | 클래식 느낌 |
| `bgm_rain.mp3` | s13~s14 | 빗소리 |
| `bgm_quiet.mp3` | s15 | 들릴 듯 말 듯 잔잔한 소리 |
| `bgm_nature.mp3` | s16~s18 | 벌레소리 + 바람소리 |
| `bgm_melancholy.mp3` | s19 | 침울하고 우울한 소리 |
| `bgm_applause.mp3` | s20~s22 | 박수 + 신나는 쇼 엔딩 음악 |

### SFX (효과음) — `assets/audio/sfx_{name}.mp3`

| 파일명 | 사용 씬 | 설명 |
|---|---|---|
| `sfx_throw.mp3` | s02 | 핸드폰 던지는 소리 |
| `sfx_sigh.mp3` | s03 | 한숨 |
| `sfx_impact.mp3` | s12 | 쿵 (추락 충격음) |
| `sfx_murmur.mp3` | s14 | 웅성웅성 군중 소리 |

### 적용 방식
- 파일 존재 시: 해당 mp3 파일 재생 (BGM은 루프, SFX는 원샷)
- 파일 미존재 시: Web Audio API 합성음으로 자동 fallback
- 포맷: mp3 권장 (wav도 가능하나 용량 큼)
